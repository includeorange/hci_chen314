# 运动有迹：在线体验入口

Streamlit课堂交互原型，界面v3.1，模型v2.0。在线入口用于教师和同学快速体验；正式提交另附本地整合包及源码。

## 部署

1. 将本目录内容放在专用GitHub仓库根目录，不要上传整个工作区或本地运行环境。
2. 登录Streamlit Community Cloud，选择该仓库及实际分支。
3. Main file path：`app/app.py`。高级设置选择Python **3.12**。
4. 等依赖安装完成并检查运行日志。获得公网HTTPS地址后，再填写提交导航。
5. 如要评卷人无需登录即可访问，设置对应的公开应用访问权限，并用未登录开发者账号的浏览器实际检查。

不要把127.0.0.1地址作为在线链接。休眠后的首次访问可能需要等待唤醒，网络可达性需在教师实际网络上验证。

## 数据处理

输入会从浏览器发送到托管服务器，在各自会话中处理。原型不主动将填写保存到数据库或文件；反馈不自动发送给项目作者。不要把本机处理说明用于此版本。平台自身的服务和日志规则由其条款决定。

模型与审核结果均在包内，不运行训练。没有上传同学测试原始记录、凭据、运行日志或逐人健康训练表。

## 本机检查

安装requirements.txt所列依赖后运行 `python -m streamlit run app/app.py`。
此目录是部署准备文件，不代表已经上线。在线与本地版模型文件保持相同SHA256。
