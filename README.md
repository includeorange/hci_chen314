# 运动有迹：在线体验入口

Streamlit课堂交互原型，界面v4.2，模型v2.0。在线入口用于教师和同学快速体验；正式提交另附本地可运行源码及运行说明。

在线体验：https://hcichen314-o4s9q6d3svqzpzesiz5pbm.streamlit.app/

侧栏“模型判断”展示五项实际输入的分布、验证集置换重要性和两条原始预测案例。重要性基于1195条验证记录、每项30次打乱、平衡准确率平均下降及±1标准差。页面读取预先计算的结果，点击特征即可查看具体分布；使用者无需重复操作30次。

## 部署

1. 将本目录内容放在专用GitHub仓库根目录，不要上传整个工作区或本地运行环境。
2. 登录Streamlit Community Cloud，选择该仓库及实际分支。
3. Main file path：`app/app.py`。高级设置选择Python **3.12**。
4. 等依赖安装完成并检查运行日志；更新已部署的main分支后，检查在线页面是否同步。
5. 如要评卷人无需登录即可访问，设置对应的公开应用访问权限，并用未登录开发者账号的浏览器实际检查。

不要把127.0.0.1地址作为在线链接。休眠后的首次访问可能需要等待唤醒，网络可达性需在教师实际网络上验证。

## 数据处理

输入会从浏览器发送到托管服务器，在各自会话中处理。原型不主动将填写保存到数据库或文件；反馈不自动发送给项目作者。不要把本机处理说明用于此版本。平台自身的服务和日志规则由其条款决定。

模型、审核结果和作业四可视化结果均在仓库内，访问页面时不运行训练或置换实验。可视化结果包含汇总分布和两条公开NHANES验证记录的模型输入、标签及输出；不包含同学测试原始记录、凭据、运行日志或完整逐人健康数据表。

## 本机检查

安装requirements.txt所列依赖后运行 `python -m streamlit run app/app.py`。
应用入口为app/app.py。在线与本地版模型文件保持相同SHA256。
